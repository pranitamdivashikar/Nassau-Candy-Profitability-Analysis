# Product Line Profitability & Margin Performance Analysis for Nassau Candy Distributor

## Project Overview
This project performs exploratory data analysis and financial performance evaluation for Nassau Candy Distributor's product lines and divisions to identify profit drivers, margin leakage, and high-risk SKUs.

## Key Features & Dashboard Modules
- **Product Profitability Overview**: Margin leaderboard and profit contribution charts.
- **Division Performance Dashboard**: Revenue vs. profit comparison and margin distributions.
- **Cost vs Margin Diagnostics**: Cost-sales scatter analysis with dynamic risk thresholds.
- **Profit Concentration Analysis**: 80/20 Pareto curve and dependency indicators.
- **Interactive User Controls**: Date range selector, division filter, margin threshold slider, and product search.
